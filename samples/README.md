# عينات رسائل المحافظ

ضع هنا **نصوص رسائل حقيقية** كما وصلت إلى الهاتف، ملفًا لكل محفظة باسم رمزها:
`jaib.txt` · `floosak.txt` · `cash.txt` · `onecash.txt` · `jawali.txt`

- كل رسالة في فقرة مستقلة (افصل بين الرسائل بسطر فارغ). الرسالة قد تمتد على أكثر من سطر.
- الأسطر التي تبدأ بـ `#` تعليقات وتُتجاهل.
- **موّه الأرقام الشخصية** قبل الحفظ (مثلًا أبدل الرقم الحقيقي بـ 777123456 واحتفظ بعدد الخانات)، لكن أبقِ الصياغة والفواصل والترتيب كما هي — هذه هي التفاصيل التي يعتمد عليها التحليل.
- تُقرأ الرسالة بعد تطبيع الأرقام (٠-٩ → 0-9) والمسافات؛ لا تحتاج تعديل ذلك يدويًا.

## التحقق

```bash
pnpm samples:check        # يطبع لكل رسالة: النمط الذي طابقها والحقول المستخرجة، أو "لم يُتعرف عليها"
pnpm test                 # يفشل إن وُجدت عينة لا تُقرأ
```

عند فشل عينة: عدّل النمط في `src/lib/parser/seed-templates.ts` (وأعد `pnpm db:seed` لتحديث قاعدة البيانات)،
أو عدّله مباشرة من لوحة المشرف `/admin/wallets/<المحفظة>` بدون نشر.

> **ملاحظة:** الرسائل الموجودة في هذه الملفات حاليًا تقديرية (لم تتوفر عينات حقيقية عند البناء). استبدلها بالنصوص الحقيقية عندما تتوفر.
